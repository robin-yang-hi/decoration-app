# 装修费用管家 — 使用说明

> 给家人用的操作指南，不需要懂技术，照着做就行。

---

## 一、怎么打开

**网址**：https://decoration-app.pages.dev

- 电脑：用浏览器（Chrome/Edge/ Safari 都行）打开上面的网址
- 手机：用手机浏览器打开同一个网址，建议"添加到主屏幕"，以后点图标就能进
- 数据存在云端，**电脑和手机看到的是同一份数据**，在哪边改都一样

---

## 二、四个页面是干什么的

底部（手机）或顶部（电脑）有 4 个标签：

| 标签 | 干什么用 |
|---|---|
| **费用总览** | 看总共花了多少钱、钱花在哪些类别、装修进度多少、图表分析 |
| **费用记录** | 一笔一笔录入花了什么钱，也可以修改和删除 |
| **预算设置** | 设置总共打算花多少钱，每个类别打算花多少 |
| **装修进度** | 装修要做的 76 件事清单，每件事标记进度 |

---

## 三、最常用的操作

### 3.1 记一笔花费

1. 点底部/顶部的 **"费用记录"**
2. 点 **"新增记录"** 按钮
3. 填写：
   - **日期**：哪天花的钱
   - **类别**：设计费 / 硬装 / 主材 / 软装 / 家电 / 人工费用 / 其他杂费（选一个）
   - **子类别**：比如瓷砖、水管、家具……（可以从建议里选，也可以自己打字）
   - **金额**：花了多少钱
   - **支付方式**：现金/微信/支付宝/银行卡/其他
   - **商家**：在哪买的（可选）
   - **备注**：其他说明（可选）
4. 点 **保存**

> 记完之后，"费用总览"页面的数字和图表会自动更新。

### 3.2 修改或删除一笔记录

1. 在"费用记录"页面找到那笔记录
2. 点那笔记录上的 **编辑** 按钮（铅笔图标）可以修改
3. 点 **删除** 按钮（垃圾桶图标）可以删掉（删了就找不回来了，谨慎操作）

### 3.3 设置预算

1. 点 **"预算设置"**
2. 填写 **总预算**（比如 15 万就填 150000）
3. 填写每个类别的预算（不填就是 0）
4. 点 **保存**

设置预算后，"费用总览"会显示预算使用率，超过 100% 会变红提醒。

### 3.4 标记装修进度

1. 点 **"装修进度"**
2. 能看到 10 个大类（前期准备、主体拆改、水电改造……）
3. 点某个大类展开，看到里面的具体事项
4. 每个事项右边有 4 个按钮：
   - ✅ **已完成**：这件事做完了
   - 🔄 **进行中**：正在做
   - ⏳ **待启动**：还没开始（默认状态）
   - ➖ **暂不涉及**：这件事不需要做（比如不做吊顶）
5. 每做完一件就点一下"已完成"，进度百分比会自动更新

> "暂不涉及"的事项不计入进度百分比。

### 3.5 看花费分析

在"费用总览"页面可以看到：
- 总共花了多少钱
- 预算用了百分之多少
- 每个类别花了多少（饼图）
- 每个月花了多少（柱状图）
- 装修整体进度

## 四、导出和分享

顶部/右上角有 4 个按钮：

| 按钮 | 用途 | 什么时候用 |
|---|---|---|
| **PDF** | 生成一份完整的装修费用报告（PDF 文件） | 给家人/朋友看，或者打印出来 |
| **CSV** | 导出费用记录表格（Excel 能打开） | 想自己用 Excel 做分析时 |
| **备份** | 导出全部数据的 JSON 文件 | 定期备份，防止数据丢失 |
| **导入** | 从之前的备份文件恢复数据 | 换设备或数据弄丢了的时候 |

### 导出 PDF 报告

点 **PDF** 按钮，等几秒，浏览器会自动下载一个 PDF 文件。里面包含：
- 费用总览（总花费、预算使用率）
- 每个类别的花费明细
- 每一笔费用记录
- 装修进度

### 定期备份建议

每隔一两个月点一次 **备份** 按钮，把 JSON 文件存到电脑或网盘里。万一云端数据出问题，可以用 **导入** 按钮恢复。

## 五、多设备使用说明

- **电脑和手机数据是同步的**：在电脑上记了一笔，手机刷新一下就能看到
- **修改后等 1-2 秒**：系统会自动保存到云端，不用手动点保存
- **看到"已同步"**：绿色圆点表示数据已经安全存到云端
- **看到"同步中"**：橙色圆点表示正在保存，稍等即可
- **看到"离线模式"**：红色圆点表示网络不通，数据存在本地，等网络恢复后会自动同步
- **换了新手机/电脑**：直接打开网址，数据会自动从云端拉取下来，不用迁移

## 六、AI 智能分析

在"费用总览"页面点右上角的 **"AI 分析"** 按钮，系统会调用 DeepSeek 人工智能，根据你的实际花费数据生成专业的装修预算分析报告，包含：
- 总览判断：一句话总结当前花费状况
- 分类分析：对花费最多的板块给出具体点评
- 预算建议：结合预算使用率给出建议
- 风险提示：指出可能超支或需要注意的地方
- 行动建议：2-3 条可操作的具体建议

点了之后等 3-10 秒就能看到分析结果。分析由 AI 生成，每次结果可能不同，比固定模板更灵活更有针对性。

> 注意：AI 分析由管理员配置的 DeepSeek API Key 提供支持，每人每分钟最多用 10 次。

## 七、常见问题

**Q：数据会丢吗？**
A：数据存在云端（Cloudflare KV），同时本地也有一份缓存。建议每隔一两个月用"备份"按钮导出一份 JSON 存到本地，双保险。

**Q：别人能看到我的数据吗？**
A：只要不把网址告诉别人，别人就看不到。但目前没有密码保护，知道网址的人都能修改数据。建议只在家人之间分享网址。

**Q：手机上字太小/布局不对？**
A：系统已经适配了手机屏幕，如果显示异常，试试刷新页面或清理浏览器缓存。

**Q：PDF 里中文是乱码？**
A：不会，系统已经专门处理了中文显示问题。如果遇到乱码，试试用 Chrome 或 Edge 浏览器导出。

**Q：能同时在电脑和手机上修改吗？**
A：可以，但建议不要同时修改同一笔记录，后保存的会覆盖先保存的。改完后另一端刷新页面即可看到最新数据。

**Q：花了一笔钱但类别里没有合适的？**
A：选"其他杂费"，然后在子类别里自己打字说明。

## 八、快速上手清单

第一次使用，按这个顺序来：

1. ✅ 打开网址，熟悉 4 个页面
2. ✅ 去"预算设置"填好总预算和分类预算
3. ✅ 去"装修进度"浏览 76 项清单，把"暂不涉及"的先标记掉
4. ✅ 花了钱就去"费用记录"记一笔
5. ✅ 做完一件装修事项就去"装修进度"标记"已完成"
6. ✅ 偶尔去"费用总览"看看花费趋势和进度
7. ✅ 每隔一两个月点一次"备份"导出数据
